# 安装指南

## 系统要求

- Windows 10 1809 或更高版本，推荐 Windows 11；
- 64 位系统；
- 能正常运行目标游戏的显卡与驱动；
- 安装和注入受保护进程时可能需要管理员权限。

## 安装

1. 只从本仓库 Releases 或作者明确发布的链接下载安装包。
2. 对照 Release 页面检查文件大小和 SHA-256。
3. 运行安装程序，选择安装目录。
4. 启动 AXRE Studio；Windows 可能显示管理员确认或未知发布者提示。
5. 首次启动后检查“设置 → 资源路径”，确认程序已找到自身 Resources 目录。

## 添加游戏

- 优先使用“自动扫描”。
- 未识别时点击“添加游戏”，选择真正渲染游戏画面的 EXE，而不是启动器 EXE。
- 正式服与测试服即使 EXE 同名，也应分别添加并保留各自完整路径。

## 首次配置

1. 选择游戏。
2. 点击“应用默认配置”。
3. 确认游戏目录中生成或更新了 `ReShade.ini`。
4. 开启“自动注入”。
5. 保持 AXRE 后台运行，再使用游戏平时的启动方式进入游戏。

## 管理员权限

AXRE 通常可以使用普通用户权限运行，但以下情况可能需要右键选择“以管理员身份运行”：

- 游戏或游戏启动器正在以管理员身份运行；
- 游戏位于受 Windows 保护的目录，普通用户无法写入相关配置；
- AXRE 提示访问被拒绝、配置写入失败或注入权限不足。

AXRE 与目标游戏的权限级别应保持一致。不要仅为图方便长期使用管理员权限，也不要用管理员权限绕过游戏、平台或反作弊机制。

## 安装更多效果

公开 Beta 仅提供最小合规效果库，不包含作者自用的完整 Shader、Texture 和 Preset。需要更多效果时，可使用以下官方入口：

- ReShade 官方 Shader 仓库：<https://github.com/crosire/reshade-shaders>
- ReShade 官方网站：<https://reshade.me/>

各个效果可能由不同作者发布，并采用不同许可。下载、修改或再分发前请阅读对应效果的许可证和说明；不要把来源不明的 DLL 或效果包放入游戏目录。

## 卸载

卸载器只应移除安装清单中的 AXRE 文件。用户生成的配置、Profiles、截图和日志默认保留，避免误删个人内容。确认不再需要后可由用户自行删除。
