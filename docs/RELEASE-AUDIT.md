# Beta 发布审计状态

## 当前结论

现有 Beta41 安装包暂不作为公开 Release 上传。原因不是程序无法运行，而是效果资源仍需继续核对再分发许可。

已确认的阻塞项：

- 候选 payload 中仍存在 `AutoHDR.fx`、`AdvancedAutoHDR.fx` 和 `Textures/METEOR/ca_lut_new.png`；
- 约 696 个效果文件不能只凭文件头确认许可证，需要按上游效果包继续核对；
- 测试包使用自签名证书，其他电脑仍会显示未知发布者。

## 公开发布前必须完成

- 移除所有需要单独授权、来源不明或无法确认再分发许可的资源；
- 为每个效果包记录上游地址、版本/提交、作者、许可证和必要署名；
- 重新构建安装包并扫描个人绝对路径、源码、PDB、密钥和混淆映射；
- 执行安装、启动、卸载和干净系统回归测试；
- 生成 SHA-256，并与最终 Release 附件一致；
- 在 Release 页面明确标注 Beta、测试签名及使用风险。

GitHub 仓库可以先公开用于项目介绍和问题反馈，但在以上项目完成前，不上传当前安装包。
