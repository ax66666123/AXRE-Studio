# Contributing and Feedback

This repository currently accepts documentation corrections, reproducible bug reports, compatibility reports, feature suggestions, and verified third-party source or license information.

Do not upload proprietary shaders, paid presets, NVIDIA runtime files, game files, signing material, personal configuration, or unsanitized logs.

When reporting a problem, include the AXRE version, Windows version, game, graphics API, launch method, reproduction steps, and sanitized logs or screenshots.
